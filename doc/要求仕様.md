# MATLAB-like C++ Library (Eigen Wrapper) 仕様書

## 1. 概要
本ライブラリは、C++の数値計算ライブラリ **Eigen (バージョン 3.3.9)** を内部エンジンとして使用し、MATLABに近い直感的なシンタックスで記述できるように設計されたラッパークラスです。

### 基本方針
*   **データ構造**: すべて `Eigen::MatrixXd`（動的サイズ・倍精度浮動小数点）で保持。
*   **メモリ配置**: MATLAB互換の **Column-Major**（列優先）。
*   **演算の基本**: 演算子オーバーロード（`+`, `-`, `*`, `/`）は、原則としてMATLABの要素ごと（`.+`, `./` 等）の挙動に準拠。

## 2. クラス構成

### `Mat` クラス
行列・ベクトルを扱うコアクラス。

| メンバ変数 / 関数 | 内容 | 備考 |
| :--- | :--- | :--- |
| `Eigen::MatrixXd data` | Eigenの実体データ | 直接アクセスも可能 |
| `rows()`, `cols()` | 行数・列数の取得 | |
| `numel()` | 全要素数の取得 | MATLABの `numel(A)` |
| `operator(r, c)` | 要素へのアクセス | 0-based indexing |

## 3. API リファレンス

### 3.1 構築・生成 (Static Methods)
| 関数 | 内容 | MATLAB相当 |
| :--- | :--- | :--- |
| `Mat(initializer_list)` | `{ {1,2}, {3,4} }` 形式で初期化 | `[1 2; 3 4]` |
| `Mat::zeros(r, c)` | $r \times c$ の零行列を生成 | `zeros(r, c)` |
| `Mat::ones(r, c)` | $r \times c$ の全要素1の行列を生成 | `ones(r, c)` |

### 3.2 基本演算 (Operators)
| 演算子 / メソッド | 内容 | MATLAB相当 |
| :--- | :--- | :--- |
| `A + B`, `A - B` | 要素ごとの加減算 | `A + B`, `A - B` |
| `A * scalar` | スカラー倍 | `A * s` |
| `A.times(B)` | 要素ごとの積 | `A .* B` |
| `A.mtimes(B)` | 行列としての積 | `A * B` |

### 3.3 数値解析関数 (Static Methods)
| 関数 | 仕様 | 説明 |
| :--- | :--- | :--- |
| `diff(A)` | 隣接要素間の差分を計算 | ベクトルの場合、長さが $-1$ された結果を返す |
| `movmean(A, k)` | 窓サイズ $k$ の移動平均 | 中心窓（Centered window）で計算 |
| `atan2(Y, X)` | 4象限逆正接 | $Y$ と $X$ の全要素に対して適用 |

## 4. 実装のポイント（開発者向けメモ）

### 4.1 要素ごとの演算 (Array Mode)
Eigenの `Matrix` 型はデフォルトで線形代数演算（行列積など）を行いますが、本ライブラリでは `.array()` メソッドを介することで、MATLABライクな要素ごとの演算を実現しています。

```cpp
// 実装例
Mat operator+(const Mat& b) const {
    return Mat(this->data.array() + b.data.array());
}
```

### 4.2 数学関数のバインド
`std::atan2` のような、Eigenに組み込まれていない関数は `binaryExpr` を用いて、各要素に対してラムダ式を適用する形で実装します。

### 4.3 スライスとブロック
MATLABの `A(1:3, :)` のような操作を拡張する場合、Eigenの `.block(startRow, startCol, rows, cols)` をラップすることで、高いパフォーマンスを維持したまま実装可能です。

## 5. 今後の拡張予定
*   **コロン演算子**: `Mat::linspace(start, end, n)` または `Mat::range(start, step, end)` の実装。
*   **統計関数**: `mean()`, `std()`, `sum()` などの集計操作（次元指定対応）。
*   **論理インデックス**: `find()` 関数や `A(A > 0)` のようなフィルタリング機能。
